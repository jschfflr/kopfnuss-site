# kopfnuss-site

Public help, privacy and imprint pages of the Kopfnuss app (qodev GmbH), served by GitHub Pages.
They are the App Store support URL (`/`) and privacy URL (`/datenschutz.html`). The app itself lives in the
private repo jschfflr/kopfnuss.

Plain HTML, no build, no external fonts or scripts. Push to `main` and Pages publishes it.
